### 1.6 AIっぽさを避ける方針

根拠: `.claude/references/anti-ai-design-checklist.md`（2026-10-23 確認）。個々の要素は単独なら問題ないが、重なると「既定値のまま」に見える。

- **見せ場は 1 つ**: トップのヒーローに、実際に読み取れる QR コード（`public/hero-qr.svg`、`https://qr-create.jp/?utm_source=qr-create&utm_medium=qr&utm_campaign=hero`）と、その指し先 URL をパラメータごとに改行したキャプションを置く。他は静かにする
- **配置**: 左寄せ。トップは「左に見出し、右に内容」の非対称 2 カラム（lg 以上）。中央寄せの巨大ヒーロー、h1 前後の pill バッジは使わない
- **区切りは罫**: 一覧（guide / use-cases / blog）、特徴、FAQ はカードの箱ではなく 1px の罫で区切る。箱（角丸の面）は /create の操作パネルと締めの案内だけ
- **同じ形のカードを並べない**: 特徴 4 項目は罫区切りの定義リスト（項目名 / 説明）
- **記事見出し**: h2 は下罫 1 本のみ、h3 は太字のみ。左ボーダー・背景色・角丸の重ねがけはしない
- **ホバー**: 色と下線の変化だけ。`translateY` で浮かせない、影を足さない
- **モーション**: 開閉（FAQ の矢印、モバイルメニュー）だけ。`prefers-reduced-motion: reduce` では止める。スクロール連動・fade-in は使わない
- **アイコン**: 絵文字を使わない。必要なら単色の小さな inline SVG
- **書体**: ALL CAPS ラベル、見出し上の eyebrow、見出しの 1 語だけの色変え、中黒連結のメタ、リンク末尾の「→」は使わない
- **コピー**: 「選ばれる理由」「今すぐ〜UP」「〜も完璧」のような定型句をやめ、何ができて押すと何が起きるかを平叙文で書く
- **コード**: `!important` を使わない（例外: `QrGeneratorSkeleton` のシマー）。上書きは修飾クラス・詳細度・CSS 変数で行う
- **品質の床**: AA コントラスト（本文 4.5:1）、全操作要素に `:focus-visible`、390px 幅まで崩れない

### 1.7 ブランドマーク（2026-10-24 追加、qr_code_create-9zf）

- **形**: QR コードのファインダーパターン（位置検出パターン）を単純化した「回」。右下の角を 1 マス分だけ外に置き、QR が組み上がる途中のような欠けを持たせる
- **元データ**: `public/brand/mark.svg`（viewBox 0 0 32 32、`shape-rendering="crispEdges"`）。形を変えるときはここだけを直し、`src/app/icon.svg` に同じ内容をコピーして `npm run build:icons` を実行する
- **色**: 藍 `#1f5fbf` の 1 色のみ。ホバー・フォーカスでも変えない。反転や 2 色化はしない
- **最小サイズ**: 16px。それ未満では使わない
- **余白**: マーク幅の 1/8 以上を空ける。apple-icon は 180px の白地に 120px のマークを中央に置き、上下左右 30px を取る
- **使う場所**: ヘッダーのロゴ横（24px、`src/components/layout/Header/BrandMark.tsx`）、favicon（`src/app/icon.svg`、`icon.png` 48px、`favicon.ico` 32px）、apple-icon（`src/app/apple-icon.png` 180px）。いずれも Next.js のメタデータファイル規約で `<head>` に出力される
- **再生成**: `npm run build:icons`（`scripts/build-icons.cjs`。playwright の Chromium で PNG と ICO を `src/app` に書き出す）

### 2.3.1 UTM ON/OFF トグル仕様

UTMパラメータ全体の有効/無効を切り替えるトグルスイッチを提供する。UTM分析が不要なユーザー向けに、UTM入力を抑止しシンプルなQRコードを生成できるようにする。

#### 配置

- **位置**: UtmBuilder ヘッダー右側（セクションタイトル「ステップ2: マーケティング効果を上げましょう」の右端）
- EffectivenessIndicator の上、もしくは並列に配置する（実装時の余白に応じて選択）
- ラベル: `UTMを設定する`（トグルの左側に併記）

#### コンポーネント

- 形態: トグルスイッチ（チェックボックスではなく、ON/OFFが視覚的にひと目で分かるスイッチ）
- アクセシビリティ: `role="switch"`, `aria-checked`, `aria-label="UTMパラメータを設定する"` を付与

#### デフォルト

- **ON**（`utmEnabled: true`）
- 既存のCRO方針（UTMによる効果測定を推奨する）と整合させるため、初期表示はON

#### OFF 時の挙動

| 対象要素 | 挙動 |
|---|---|
| `UtmField` (5つ全て: source/medium/campaign/term/content) | `disabled=true` を渡してグレーアウト・操作不能化（淡色化、カーソル: not-allowed） |
| 詳細設定アコーディオン (utm_term / utm_content) | 開閉操作は可能だが、中の入力欄はグレーアウト |
| UtmGuide（用途別設定例カード） | 非表示にする（OFF時に「設定例から選ぶ」は意味を持たないため） |
| EffectivenessIndicator | 淡色化（グレースケール表示）し、メッセージを「UTM未使用」と表示 |
| 損失回避警告バナー | 非表示にする |
| UrlPreview（生成URL表示） | `?utm_*` を含まない URL を表示 |
| 生成されるQRコードのURL | UTMパラメータを付与しない（`buildUtmUrl(baseUrl, utm, false)` 経由で baseUrl をそのまま使用） |

#### 値の保持と復元

- OFF 時も `utm` フィールドの入力値はメモリ上に**保持**する
- 再度 ON に戻したとき、入力されていた値はそのまま復元される
- これは [データモデル設計 2.3 QRコード生成状態](./data-model.md#23-qrコード生成状態) の `utmEnabled` 仕様に基づく

#### baseUrl に既存クエリがある場合の扱い

- ユーザーが `https://example.com/page?id=123` のような既存クエリを持つURLを入力した場合、OFF時は **既存クエリを温存したまま** UTM付与のみを抑止する
- つまり、生成URL = `https://example.com/page?id=123`（変更なし）
- ON時は通常通り `&utm_source=...` の形式で追加する

#### アナリティクス

- ON/OFF切替時に GA4 イベント `utm_toggled` を発火する
  - パラメータ: `{ enabled: boolean }`
  - 関数: `trackUtmToggled(enabled: boolean)` を `lib/analytics/track.ts` に追加（[データモデル設計 4.1 イベント定義](./data-model.md#41-イベント定義) 参照）

## 3. プログレッシブディスクロージャー

[マーケティング戦略 セクション7](../marketing-strategy.md) のCRO施策に基づく段階的UI表示。

### 3.1 ステップ遷移ルール

| 現在のステップ | 次のステップへの条件 | 表示変化 |
|---|---|---|
| ステップ1（URL入力） | 有効なURLが入力された | ステップ2が自動展開。QRプレビューが表示される |
| ステップ2（UTM設定） | 常にアクセス可能（URLが有効なら） | ステップ3のタブが有効化 |
| ステップ3（装飾設定） | 常にアクセス可能（URLが有効なら） | ダウンロードボタンが有効化 |
| ダウンロード | QRコードが生成済み | ダウンロード実行可能 |

- 各ステップは折りたたみ可能（アコーディオン形式）
- 一度展開したステップは自由に開閉できる
- ProgressBarは常に表示

### 3.2 ProgressBar の完了度算出

完了度は3段階（33% / 67% / 100%）で算出する。ダウンロードはQRコード完成後のアクションであり、完成度には含めない。

```typescript
function getCompletionPercent(state: QrState): number {
  let steps = 0;

  // ステップ1: URL入力 (+33%)
  if (state.isUrlValid) steps += 1;

  // ステップ2: UTM設定 (+33%)
  // utmEnabled=false の場合は「UTMは使わない」とユーザーが明示的に選択したため、
  // 自動完了扱い（+1）とする。これにより「UTMをOFFにしただけで進捗が止まる」
  // 不自然な挙動を避ける。
  if (!state.utmEnabled) {
    steps += 1;
  } else {
    const hasUtm = /* source/medium/campaign/term/contentのいずれかが入力済み */;
    if (hasUtm) steps += 1;
  }

  // ステップ3: 装飾設定 (+34%)
  const hasDecoration = /* 色変更/フレーム/キャプション/ロゴのいずれかが設定済み */;
  if (hasDecoration) steps += 1;

  return Math.round((steps / 3) * 100);
}
```

**UTM OFF時の完了度判定方針**:
- `utmEnabled === false` の場合、UTMステップは**自動完了扱い**（+1）とする
- 理由: ユーザーがOFFを明示的に選択した時点で「このステップに用はない」という意思表示と解釈できる。OFFにしただけで進捗が67%から33%に下がってしまうと UX として不自然
- 代替案として「OFF時は分母から除外（2ステップ中の達成率で算出）」も検討したが、UI上のステップ表示数が動的に変動するため見送り。固定3ステップで自動完了扱いとする方が実装と表示が安定する

### 3.3 ProgressBar のメッセージ

| 完了度 | メッセージ |
|---|---|
| 0% | URLを入力してQRコードを作成しましょう |
| 33% | UTMパラメータを設定するとマーケティング効果UP！ |
| 67% | 装飾でQRコードをもっと魅力的に |
| 100% | QRコードが完成しました！ |

Zeigarnik Effect（未完了タスクが記憶に残る効果）を活用し、常に「あと少し」感を演出する。

## 6. レスポンシブデザイン方針

### 6.1 ブレークポイント別レイアウト

| コンポーネント | スマートフォン | タブレット | デスクトップ |
|---|---|---|---|
| ヘッダーナビ | ハンバーガーメニュー | ハンバーガーメニュー | 横並びリンク |
| QrGenerator | 1カラム | 1カラム | 2カラム（入力/プレビュー） |
| QRプレビュー | スティッキー（上部固定） | スティッキー（上部固定） | 右カラム |
| 特徴セクション | 1カラム | 2カラム | 3カラム |
| 用途別カード | 2カラム | 3カラム | 4カラム |
| フレーム選択 | 2カラムグリッド | 3カラムグリッド | 4カラムグリッド |
| 装飾プリセット | 2カラムグリッド | 3カラムグリッド | 5カラム横並び |

### 6.2 スマートフォン固有の配慮

- タップターゲットは最低44x44px
- フォーム要素は十分な余白を確保（誤タップ防止）
- QRプレビューはスクロール追従（position: sticky）
- ダウンロードボタンは画面下部に固定表示（固定フッター）
- ツールチップはモーダル表示に切り替え

## 7. アクセシビリティ

[要件定義書 5.3](../requirements.md) に基づきWCAG 2.1 Level AA準拠を目標とする。

### 7.1 キーボード操作

| 操作 | キー | 対象 |
|---|---|---|
| フォーカス移動 | Tab / Shift+Tab | 全インタラクティブ要素 |
| 選択/実行 | Enter / Space | ボタン、リンク、チェックボックス |
| ドロップダウン操作 | ↑↓ | Select コンポーネント |
| タブ切り替え | ←→ | Tabs コンポーネント |
| モーダル閉じる | Escape | ツールチップ、モバイルナビ |
| 色入力 | 直接テキスト入力 | ColorPicker（キーボードで色コード入力可能） |

### 7.2 ARIA属性

```html
<!-- ProgressBar -->
<div role="progressbar" aria-valuenow="50" aria-valuemin="0" aria-valuemax="100"
     aria-label="QRコード作成の進捗">

<!-- ツールチップ -->
<button aria-describedby="tooltip-utm-source">
  utm_source <span>?</span>
</button>
<div id="tooltip-utm-source" role="tooltip">...</div>

<!-- タブ -->
<div role="tablist" aria-label="装飾設定">
  <button role="tab" aria-selected="true" aria-controls="panel-preset">プリセット</button>
  <button role="tab" aria-selected="false" aria-controls="panel-logo">ロゴ</button>
</div>
<div role="tabpanel" id="panel-preset" aria-labelledby="tab-preset">...</div>

<!-- アコーディオン（ステップ） -->
<button aria-expanded="true" aria-controls="step2-content">
  ステップ2: UTMパラメータ設定
</button>
<div id="step2-content" role="region">...</div>

<!-- カラーピッカー -->
<label for="fg-color">前景色</label>
<input id="fg-color" type="color" aria-label="QRコードの前景色を選択">
<input type="text" aria-label="カラーコードを直接入力" pattern="#[0-9a-fA-F]{6}">

<!-- エラーメッセージ -->
<input aria-invalid="true" aria-describedby="url-error">
<span id="url-error" role="alert">有効なURLを入力してください</span>
```

### 7.3 色のコントラスト

- テキストと背景のコントラスト比は4.5:1以上（WCAG AA基準）
- 大きいテキスト（18px bold以上）は3:1以上
- フォーカスリングの視認性を確保
- QRコードのコントラスト警告を表示（3:1未満で警告）

### 7.4 スクリーンリーダー対応

- QRコードプレビュー画像に適切な `alt` テキスト: 「{URL}のQRコードプレビュー」
- 装飾変更時にライブリージョンで状態を通知: `aria-live="polite"`
- ダウンロード完了時に通知: `aria-live="assertive"`
- フォームのラベルとエラーメッセージを関連付け

## 8. マイクロインタラクション

### 8.1 QRコード更新アニメーション

- 入力変更後のQRコード再生成時、フェードイン/アウトで切り替え
- `transition: opacity 200ms ease`
- 生成中はスケルトン表示

### 8.2 ProgressBar アニメーション

- ステップ完了時にバーがスムーズに伸びる
- `transition: width 500ms ease-out`
- 完了時にパルスアニメーション

### 8.3 ステップ展開アニメーション

- アコーディオンの開閉は `max-height` + `opacity` でスムーズに
- `transition: max-height 300ms ease, opacity 200ms ease`

### 8.4 ボタンフィードバック

- ホバー: 背景色が暗くなる + 微小な上移動（`transform: translateY(-1px)`）
- クリック: 押し込みアニメーション（`transform: scale(0.98)`）
- ダウンロード完了: チェックマークアニメーション

### 8.5 コピーボタン

- クリック時: 「コピーしました」のトースト表示（2秒後に自動消去）
- アイコンがクリップボード → チェックマークに一時的に変化

## 9. エラー・警告表示パターン

### 9.1 バリデーションエラー

```
赤色ボーダー + エラーメッセージ（入力フィールド直下）
```

| 対象 | エラー条件 | メッセージ |
|---|---|---|
| URL | 空白 | URLを入力してください |
| URL | 無効な形式 | 有効なURLを入力してください（例: https://example.com） |
| URL | 長すぎる（2048文字超） | URLが長すぎます。短いURLを使用してください |
| ロゴファイル | サイズ超過 | ファイルサイズが大きすぎます（上限: 500KB） |
| ロゴファイル | 非対応形式 | PNG, JPG, SVG形式のファイルを選択してください |

### 9.2 警告メッセージ

```
黄色背景 + 警告アイコン + メッセージ
```

| 対象 | 警告条件 | メッセージ |
|---|---|---|
| コントラスト | 比率3:1未満 | コントラストが低いため、QRコードが読み取りにくくなる可能性があります |
| UTM未設定 | 0個 | UTMパラメータを設定すると、Google Analyticsで効果測定ができます |
| キャプション | 15文字超 | キャプションが長めです。印刷時に見切れる可能性があります |

### 9.3 成功メッセージ

```
緑色背景 + チェックアイコン + メッセージ
```

| 対象 | 条件 | メッセージ |
|---|---|---|
| URLコピー | コピー完了 | URLをコピーしました |
| ダウンロード | 完了 | QRコードをダウンロードしました |
