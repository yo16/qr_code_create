店やイベント会場に置いたQRコードの上に、知らないうちに別のQRコードのシールが貼られていたら、読み取ったお客さまは偽の画面に案内されます。お客さまが被害に遭うだけでなく、店の信用も傷つきます。

QRコードの注意喚起は、読み取る側に向けたものが多くあります。この記事はQRコードを印刷して置く側、配る側に向けて書きました。店、イベント、教室、小さな会社などで使えます。

先に断っておくと、この記事で守る対象は、URLを開くQRコードです。決済用のQRコードの置き方はお使いの決済サービスの案内に従ってください。また、ここに書く工夫で被害を防げると言い切ることはできません。貼り替えをしにくくし、気づきやすくするためのものです。

## 警視庁が挙げる貼り替えの手口

警視庁は「QRコードを利用する時の注意点」で、QRコードを悪用した手口を3つ挙げています。偽のメール（フィッシング）によるQRコード詐欺、犯人側から送ったQRコードを読み取らせる手口、そしてQRコードの貼り替えです。

貼り替えはフードコートなどで、正規のQRコードの上に偽物のシールを貼る手口です。偽の決済画面に移動させ、クレジットカード情報を盗もうとします。

このページが利用者に勧める対策は、読み取る前に指で触ってみること、不審に思ったら店員に確認すること、読み込んだあとに表示された内容を確認することです。どれも読み取る側に向けたもので、置く側に向けた記述はありません。

このサイトの見方では、置く側が何もしなければ、利用者が頼れるのは自分の確認だけです。

## 公的機関が置く側に勧めていること

埼玉県警察のサイバーセキュリティレポート（2025年7月）は、企業や団体に向けて「二次元コード」を悪用したトラブルの対策を紹介しています。ここでいう二次元コードは、この記事でいうQRコードのことです。3つの手口が載っています。

| 手口 | 内容 | 資料が勧める対策 |
|---|---|---|
| 他人の二次元コードによる不正支払い | 他人のコードのスクリーンショットを店員に見せ、支払いを免れる | 提示された画面が静止画でないかを確認する |
| 利用客に偽の二次元コードを読み込ませる | 店のコードを置いていたところ、別のコードのシールが貼られ、支払いが別の口座に送られる | レジカウンターに置いたままにしない |
| 偽の決済完了画面を提示する | 偽の画面を見せて、支払ったように装う | 支払い状況を管理、確認できる環境をつくる |

貼り替えに当たるのは、2つ目の手口です。1つ目と3つ目は決済の話なので、ここでは触れるだけにします。

2つ目の手口への対策として資料に書かれているのは、コードをレジカウンターに置いたままにしないことです。ここまでが警察の資料に書かれていることです。

## ここからは、このサイトの提案

次の節からは警察の勧めではありません。警察の資料は決済用のコードの話が中心です。以下はその考え方をURLを開くQRコードに当てはめて、QR Code Createが考えた工夫です。効果を確かめた方法ではないので、お店の事情に合わせて取り入れてください。

## 貼り替えをしにくくする

まず、シールで貼るのをやめ、ポスターやメニュー、POPなどの印刷物にQRコードを刷り込みます。刷り込んだ印刷物なら、もとの面は平らです。あとから貼られたシールは、触ると段差で見つけやすくなります。警視庁が利用者に勧める、触ってみる確認が効きやすくなります。

ケースやラミネートの中に入れるのも選択肢です。ただし、その上からシールを貼られることはあります。貼られること自体は止められません。

目と手の届く場所に置くことも大切です。目の届かない場所に長く置くと、シールを貼られても気づきにくくなります。レジに置いたままにしないという埼玉県警察の勧めと、同じ考え方です。

## 利用者が確かめられるようにする

警視庁は利用者に、触ってみること、店員に聞くこと、表示を確認することを勧めています。置く側はこの3つを助けられます。

QRコードのそばに、店や会社の名前、読み取ると何が開くか（例: 「メニューが開きます」）、飛び先のドメイン（例: `example.com`）の3つを書いておきます。

読み取った直後にカメラが表示するURLのドメインが、そばに書いたドメインと同じなら、利用者は確かめられます。違えば、おかしいと気づけます。

店員がお客さまから「このQRコードは本物ですか」と聞かれることがあります。答えられるように、どこにどのQRコードを置いたか、飛び先はどこかを、働く人みんなで共有しておいてください。

## 短縮URLを使わず、自分のドメインを直接書き込む

短縮URLや中継サービスを通すと、読み取った直後に表示されるのは、短縮サービスのドメインです。そばに書いたドメインとは違うので、利用者が読み取った直後に確かめる手がかりが一つ減ります。

自分のドメインのURLを直接書き込めば、読み取った直後に表示されるドメインと、そばに書いたドメインが同じになります。QR Code Createが作るのは、URLをそのまま書き込む静的QRコードです。中継サービスを通らないので、サービスの契約が終わっても読み取れなくなりません。静的QRコードと動的QRコードの違いは「[QRコードに有効期限はある？](/blog/qr-code-expiration)」で説明しています。

計測のためにUTMパラメータを付けても、ドメインは変わりません。

一方で、短縮URLにも利点があります。書き込む文字が少ないほど、QRコードのドット（四角）の数が減るからです。同じ大きさで印刷した場合、一つひとつのドットが大きくなるので、読み取りやすくなります。

どちらがよいかは、場面によって変わります。店頭など接客の場面では、短縮しないほうがよいと考えます。お客さまがその場で読み取り、表示されたドメインを、そばに書いたドメインや店の名前と見比べられるからです。

どの場面でも、UTMパラメータを付けたときなどにURLが長くなりすぎると、ドットが細かくなって読み取りにくくなります。この点は「[よくある質問と便利なTips](/guide/tips)」にも書いてあります。印刷する大きさで、自分のスマートフォンで実際に読み取って確かめてください。

## 置いたQRコードを点検する

置いたQRコードの一覧を作っておきます。場所と飛び先の2つを書けば十分です。

開店前など、決まったタイミングで次の2つを行います。

1. 触ってみて、シールの段差がないかを見る
2. 実際に読み取って、飛び先が正しいかを確かめる

チラシなど、配った印刷物は点検できません。卓上、壁、看板のように、置きっぱなしになるものを優先してください。

## 貼り替えを見つけたとき

まず、そのQRコードを使うのをやめ、読み取られないようにします。次に、貼られた状態の写真を残します。そのうえで警察に相談してください。

読み取った可能性のあるお客さまへの知らせ方も、あらかじめ決めておくと慌てません。貼り紙、店内の声かけ、公式サイトやSNSでの告知などが考えられます。
