## ダウンロード形式の種類

QR Code Createでは、3種類のファイル形式でQRコードをダウンロードできます。

- **PNG**: 画像ファイル形式
- **SVG**: ベクター形式
- **PDF**: 印刷向けドキュメント形式

それぞれの特徴と適した用途を紹介します。

## PNG形式

PNGは、もっとも一般的な画像ファイル形式です。Webサイトへの掲載やSNSでの共有、デジタル媒体での使用に適しています。

### PNGが向いている用途

- Webサイトやブログへの掲載
- メールへの添付
- SNSでの共有
- プレゼンテーション資料への挿入

### 注意点

PNGはラスター形式（ドットの集まり）のため、大きく拡大すると画質が粗くなります。印刷物に使う場合は、解像度を高めに設定するか、SVGやPDF形式の利用を検討してください。

## SVG形式

SVGは、ベクター形式の画像ファイルです。拡大・縮小しても画質が劣化しないのが最大の特徴です。

### SVGが向いている用途

- 大きく印刷するポスターや看板
- サイズが未定の段階でのデータ作成
- デザインソフト（Illustrator、Figmaなど）での編集
- Webサイトでの高品質表示

### 注意点

SVGファイルを直接開けないアプリケーションもあります。メールに添付する場合や、対応していないソフトで使う場合はPNG形式を選んでください。

## PDF形式

PDFは、印刷物への入稿に適したドキュメント形式です。印刷会社への入稿や、印刷物のレイアウトに直接貼り付ける場合に便利です。

### PDFが向いている用途

- チラシやパンフレットへの入稿
- 印刷会社へのデータ納品
- 印刷物のレイアウトソフトへの配置
- 高品質な印刷出力

### 注意点

PDFファイルはWebサイトへの直接掲載には向いていません。Web用途にはPNGまたはSVGを使用してください。

## 印刷用ポスター（A4 PDF）

[印刷用ポスター](/poster)のページで、説明文とQRコードを組み合わせたカードを、A4用紙に4枚並べたPDFを作れます。通常のPDF形式とは別の機能です。

### できること

- A4縦1ページに、同じカードを2列×2段で4枚並べたPDFを作れます
- 1枚のカードはA4の4分の1で、105mm × 148.5mmです
- ページの中央に、十字の切り取り線（破線）が入ります
- 説明文はMarkdownで書けます（見出し、太字、リストなど）。目安は500文字までです。超えても入力はできますが、カードからはみ出した分は印刷されません
- [QRコード作成ツール](/create)で設定した色・フレーム・ロゴ・キャプションなどの装飾と、UTMの設定を引き継ぎます。印刷用ポスターのページでも、URLとUTMは編集できます

### 使い方

1. [QRコード作成ツール](/create)でQRコードを作ります
2. ダウンロード欄の「印刷用ポスターを作る →」を押します
3. 印刷用ポスターのページで、説明文を入力します
4. QRコードの準備が終わったら、「PDFをダウンロード（A4印刷用）」を押します

印刷用ポスターのページを直接開いて使うこともできます。その場合は、URLの入力から始めます。

### 印刷用ポスターが向いている用途

- イベントの受付や会場での掲示
- アンケートの案内
- 店舗のレジ横や卓上での案内

印刷して切り分けて配ったり、掲示したりする場合に便利です。

### 注意点

- 説明文が空のときは、ダウンロードできません
- PDFは画像として作られるため、文字を後から編集することはできません。編集が必要な場合は、SVG形式か通常のPDF形式を使ってください

## 解像度の選び方

PNG形式を選んだ場合、出力解像度を選択できます。3段階の解像度が用意されています。

### 通常（1x）

- 標準的な解像度です
- ファイルサイズ: 約20KB
- Webサイトやデジタル媒体での使用に適しています
- 画面上での表示には十分な品質です

### 2倍（2x）

- 通常の2倍の解像度です
- ファイルサイズ: 約80KB
- チラシや名刺など、一般的な印刷物に適しています
- Retinaディスプレイでの表示にも対応できます

### 4倍（4x）

- 通常の4倍の高解像度です
- ファイルサイズ: 約300KB
- ポスターや看板など、大きく印刷する場合に適しています
- 最高品質が必要な印刷物におすすめです

## 用途別おすすめ形式

| 用途 | おすすめ形式 | 解像度 |
|---|---|---|
| Webサイトに掲載 | PNG | 通常（1x） |
| メールに添付 | PNG | 通常（1x） |
| 名刺に印刷 | PNG または SVG | 2x以上 |
| チラシに印刷 | SVG または PDF | - |
| ポスターに印刷 | SVG または PDF | - |
| イベントやアンケートの案内を印刷して配る | 印刷用ポスター（A4 PDF） | - |
| 印刷会社に入稿 | PDF | - |
| デザインソフトで編集 | SVG | - |

## まとめ

ダウンロード形式は用途に合わせて選びましょう。

- **Web・デジタル用途**: PNG形式（通常解像度）
- **一般的な印刷物**: PNG形式（2x以上）またはSVG形式
- **大判印刷・入稿**: SVGまたはPDF形式
- **案内を印刷して配る・掲示する**: 印刷用ポスター（A4 PDF）

迷った場合は、PNG形式の2x解像度を選んでおけば、多くの用途に対応できます。
