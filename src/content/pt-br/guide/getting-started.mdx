## O que o QR Code Create faz

O QR Code Create transforma uma URL em um QR Code. Você pode mudar as cores, adicionar um logo e colocar uma moldura e uma legenda ao redor do código. Também é possível adicionar parâmetros UTM para ver no Google Analytics de onde vieram os seus visitantes.

Criar um QR Code leva três etapas.

1. Digite a URL
2. Personalize o design (opcional)
3. Baixe o arquivo

**[Abrir o gerador de QR Code](/pt-br/create)** (grátis, sem cadastro). Você pode deixar este guia aberto enquanto trabalha.

## Etapa 1: digite a URL

Abra o [gerador de QR Code](/pt-br/create) e digite no campo de URL, em "Digite a URL", o endereço para o qual você quer levar as pessoas.

O QR Code aparece na pré-visualização assim que você digita e é atualizado a cada mudança.

A ferramenta verifica a URL enquanto você digita. Se ela não começar com `https://` ou `http://`, aparece uma mensagem de erro. Corrija a URL antes de continuar.

## Etapa 2: personalize o design (opcional)

O painel "Personalize o design" muda a aparência do QR Code. Você pode pular esta etapa. Um QR Code simples é escaneado tão bem quanto os outros.

### Escolha uma predefinição

Há cinco predefinições.

- **Simples**: preto e branco limpo
- **Empresarial**: sóbrio e confiável
- **Casual**: amigável, com cores naturais
- **Elegante**: refinado e discreto
- **Pop**: brilhante e colorido

Selecione uma predefinição e a pré-visualização muda na hora.

### Ajuste os detalhes

Depois de escolher uma predefinição, você pode continuar ajustando.

- **Logo**: coloque a sua própria imagem de logo no centro do QR Code
- **Cor**: mude as cores do primeiro plano e do fundo
- **Moldura**: escolha uma moldura para ficar ao redor do QR Code
- **Legenda**: edite o texto exibido abaixo do QR Code

Mantenha o primeiro plano bem mais escuro que o fundo. A ferramenta mostra a taxa de contraste e avisa quando o código pode ser difícil de escanear.

## Etapa 3: baixe o arquivo

Quando o design estiver como você quer, use os botões de download para baixar o arquivo.

### Escolha um formato de arquivo

- **PNG**: um formato de imagem padrão para telas e para a web
- **SVG**: um formato vetorial que continua nítido em qualquer tamanho, ideal para impressões grandes
- **PDF**: um formato para colocar o código em um layout de impressão ou enviar a uma gráfica

### Escolha uma resolução

No PNG, você também pode escolher uma resolução.

- **Padrão**: o tamanho normal, para sites e outras telas
- **2x**: para impressão (recomendado), como folhetos e cartões de visita
- **4x**: alta qualidade, para pôsteres e placas. O arquivo é maior

## Adicione parâmetros UTM

Se você distribui o mesmo QR Code em vários folhetos ou cartões de visita e quer saber qual deles trouxe uma visita, adicione parâmetros UTM à URL.

Abra a seção "Adicionar parâmetros UTM" abaixo do campo de URL. Ela tem campos para origem, mídia e campanha, além de predefinições para casos comuns, como cartões de visita e folhetos. Ao escolher uma predefinição, os parâmetros são preenchidos para você.

O Google Analytics então lista cada visita pela origem, mídia e campanha que você definiu.

## Resumo

Criar um QR Code com o QR Code Create leva três etapas.

1. **Digite a URL**: a pré-visualização é atualizada enquanto você digita
2. **Personalize o design (opcional)**: use uma predefinição ou ajuste cada detalhe
3. **Baixe o arquivo**: escolha um formato e uma resolução
