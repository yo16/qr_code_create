2027年用の年賀はがきの当初発行枚数は5.6億枚です。2026年用の7.5億枚に対して約74.3%、つまり約25.7%の減少です。発行枚数が減るのは16年連続だと、共同通信が伝えています（出典は記事の最後に載せました）。

出す枚数が減るほど、1枚の年賀状がどれだけ読まれたかを知りたくなります。お客さまや取引先に年賀状を出しているなら、QRコードを載せて、年賀状から来た人を数えられます。載せる場所と大きさ、UTMの付け方、間に合わせる日程を、この順に書きました。

## 年賀状にQRコードを載せる場所と大きさ

QRコードは、通信面（文面を書く側）に載せます。年賀状のデザインに、一言を添えた小さな枠を作って置くのが、読み取ってもらいやすい形です。「年始のお知らせはこちら」のように、読み取ると何が見られるかを書いておくと、受け取った人が迷いません。

はがきは100mm × 148mmです。QRコードの大きさは、チラシの目安に合わせて、最小20mm × 20mm、推奨30mm × 30mmにしてください。周囲の余白は3mm以上必要です。名刺では15mmから20mmが目安ですが、はがきは名刺より広いので、余裕のある大きさにできます。細かい目安は「[チラシ・フライヤー用QRコードの作り方](/use-cases/flyer)」と「[名刺用QRコードの作り方](/use-cases/business-card)」にあります。

## 飛び先の例

年賀状は、受け取った人が正月に読むものです。そのときに役立つ先を選びます。

たとえば、年始の営業日と営業時間のお知らせ、初売りやセールのページ、予約や申し込みのフォーム、新しい住所や電話番号などの連絡先です。

飛び先のページはスマートフォンで見やすい作りにしておいてください。正月の間は、ページを更新しなくても内容が合っているものを選ぶと安心です。

## UTMパラメータの付け方

UTMパラメータは、URLの後ろに付ける目印です。年賀状から来たアクセスを、Google Analyticsなどで他の流入と分けて見られます。UTMそのものの意味は「[UTMパラメータとは](/guide/utm-parameters)」で説明しています。

値の例は次のとおりです。

| パラメータ | 値の例 | 役割 |
|---|---|---|
| utm_source | `nenga` | 年賀状 |
| utm_medium | `print` | 印刷物 |
| utm_campaign | `nenga_2027` | 2027年の年賀状 |
| utm_content | `customer` | お客さま向けの年賀状 |
| utm_content | `partner` | 取引先向けの年賀状 |

utm_mediumのprintは、QR Code Createのプリセット（qrとprint）にある値です。utm_sourceの年賀状向けの値はプリセットにありませんが、QR Code Createでは入力欄に好きな値を自由に入力できます。年賀状を表す値は、自分で決めて入力してください。

お客さま向けと取引先向けは、utm_contentで分けます。作成画面では「utm_content（コンテンツ識別子）」の入力欄に、customerやpartnerを入れてください。2種類のQRコードを別々に作れば、どちらの年賀状がよく読まれたか比べられます。utm_campaignに年を入れておけば、来年以降の年賀状と並べて見られます。

## 付けてはいけない値と、印刷前の確認

受け取った人を一人ずつ見分ける値は、付けないでください。名前や顧客番号をURLに入れると、個人情報がアクセスの記録に残ります。分けるのは、お客さま向けと取引先向けのように、束ごとにとどめます。

印刷の前に、スマートフォンで読み取りを確かめてください。試しに印刷した紙で確かめると、色や大きさの問題に気づけます。印刷したあとで飛び先のURLは変えられません。

## 1月の初めにGA4で見る

年賀状が届くのは、1月の初めです。そのころにGA4を開いて、utm_campaignがnenga_2027のアクセスを見ます。見方は「[UTMパラメータとは](/guide/utm-parameters)」の「GA4で確認する手順」にまとめています。

## 間に合わせるための日程

年賀はがきは、郵便局で2026年11月2日から2027年1月15日まで販売されます。販売期間は、従来の1月10日ごろから延びました。

元日に届けるための差し出しの目安は、12月27日です。前回（2026年用）の12月25日から、2日繰り下がりました。QRコードの確認と印刷は、その前に終えてください。

年賀状を出せなかった場合や、年賀状じまいをする場合に出す寒中見舞いのはがきでも、同じ方法でQRコードを載せて数えられます。utm_campaignの値を変えて、年賀状と分けて見てください。

## 作業の順番

先に飛び先のページを決め、QRコードを作って、試し刷りで読み取りを確かめます。問題がなければ本番を印刷し、12月27日までに差し出します。年が明けたら、1月の初めにGA4で数字を確認してください。

年賀状のQRコードは、QR Code Createで作れます。
