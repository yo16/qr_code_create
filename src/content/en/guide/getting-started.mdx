## What QR Code Create does

QR Code Create turns a URL into a QR code. You can change the colors, add a logo, and put a frame and caption around the code. You can also add UTM parameters, so you can see in Google Analytics where your visitors came from.

Making a QR code takes three steps.

1. Enter your URL
2. Customize the design (optional)
3. Download the file

**[Open the QR code generator](/en/create)** (free, no sign-up). You can keep this guide open while you work.

## Step 1: Enter your URL

Open the [QR code generator](/en/create) and type the URL you want to link to in the URL field under "Enter your URL".

The QR code appears in the preview as soon as you type, and it updates with every change.

The tool checks the URL as you type. If it does not start with `https://` or `http://`, an error message appears. Fix the URL before you move on.

## Step 2: Customize the design (optional)

The "Customize the design" panel changes how the QR code looks. You can skip this step. A plain QR code scans just as well.

### Choose a preset

There are five presets.

- **Simple**: clean black and white
- **Business**: calm and trustworthy
- **Casual**: friendly, natural colors
- **Elegant**: refined and understated
- **Pop**: bright and colorful

Select a preset and the preview changes right away.

### Adjust the details

After you pick a preset, you can keep adjusting it.

- **Logo**: place your own logo image in the center of the QR code
- **Color**: change the foreground and background colors
- **Frame**: choose a frame to go around the QR code
- **Caption**: edit the text shown below the QR code

Keep the foreground much darker than the background. The tool shows a contrast ratio and warns you when the code may be hard to scan.

## Step 3: Download the file

When the design looks right, use the download buttons to save the file.

### Choose a file format

- **PNG**: a standard image format for screens and the web
- **SVG**: a vector format that stays sharp at any size, which suits large prints
- **PDF**: a format for placing the code in a print layout or sending it to a printer

### Choose a resolution

For PNG, you can also pick a resolution.

- **Standard**: the default size, for websites and other screens
- **2x**: for print (recommended), such as flyers and business cards
- **4x**: high quality, for posters and signs. The file is larger

## Add UTM parameters

If you hand out the same QR code on several flyers or business cards and want to know which one brought a visit, add UTM parameters to the URL.

Open the "Add UTM parameters" section below the URL field. It has fields for source, medium, and campaign, plus presets for common cases such as business cards and flyers. Choosing a preset fills in the parameters for you.

Google Analytics then lists each visit under the source, medium, and campaign you set.
