## Qué hace QR Code Create

QR Code Create convierte una URL en un código QR. Puedes cambiar los colores, agregar un logotipo y poner un marco y una leyenda alrededor del código. También puedes agregar parámetros UTM para ver en Google Analytics de dónde vienen tus visitas.

Crear un código QR lleva tres pasos.

1. Escribe tu URL
2. Personaliza el diseño (opcional)
3. Descarga el archivo

**[Abrir el generador de códigos QR](/es/create)** (gratis, sin registro). Puedes dejar esta guía abierta mientras trabajas.

## Paso 1: escribe tu URL

Abre el [generador de códigos QR](/es/create) y escribe la URL a la que quieres enlazar en el campo URL, bajo "Escribe tu URL".

El código QR aparece en la vista previa en cuanto escribes y se actualiza con cada cambio.

La herramienta comprueba la URL mientras escribes. Si no empieza por `https://` o `http://`, aparece un mensaje de error. Corrige la URL antes de continuar.

## Paso 2: personaliza el diseño (opcional)

El panel "Personaliza el diseño" cambia el aspecto del código QR. Puedes omitir este paso. Un código QR sencillo se escanea igual de bien.

### Elige un diseño predefinido

Hay cinco diseños predefinidos.

- **Simple**: blanco y negro, limpio
- **Negocios**: sereno y de confianza
- **Informal**: cercano, con colores naturales
- **Elegante**: refinado y discreto
- **Pop**: brillante y colorido

Selecciona un diseño y la vista previa cambia al instante.

### Ajusta los detalles

Después de elegir un diseño, puedes seguir ajustándolo.

- **Logotipo**: coloca tu propia imagen de logotipo en el centro del código QR
- **Color**: cambia los colores de primer plano y de fondo
- **Marco**: elige un marco para rodear el código QR
- **Leyenda**: edita el texto que se muestra debajo del código QR

Mantén el primer plano mucho más oscuro que el fondo. La herramienta muestra una relación de contraste y te avisa cuando el código puede ser difícil de escanear.

## Paso 3: descarga el archivo

Cuando el diseño te convenza, usa los botones de descarga para guardar el archivo.

### Elige un formato de archivo

- **PNG**: un formato de imagen estándar para pantallas y la web
- **SVG**: un formato vectorial que se mantiene nítido a cualquier tamaño, ideal para impresiones grandes
- **PDF**: un formato para colocar el código en un diseño de impresión o enviarlo a la imprenta

### Elige una resolución

En PNG, también puedes elegir una resolución.

- **Estándar**: el tamaño por defecto, para sitios web y otras pantallas
- **2x**: para imprimir (recomendado), como folletos y tarjetas de visita
- **4x**: alta calidad, para pósteres y carteles. El archivo es más grande

## Agrega parámetros UTM

Si repartes el mismo código QR en varios folletos o tarjetas de visita y quieres saber cuál trajo una visita, agrega parámetros UTM a la URL.

Abre la sección "Agrega parámetros UTM" debajo del campo URL. Tiene campos para el origen, el medio y la campaña, además de opciones para casos habituales como tarjetas de visita y folletos. Si eliges una opción, los parámetros se rellenan por ti.

Después, Google Analytics muestra cada visita según el origen, el medio y la campaña que configuraste.

## Resumen

Crear un código QR con QR Code Create lleva tres pasos.

1. **Escribe tu URL**: la vista previa se actualiza mientras escribes
2. **Personaliza el diseño (opcional)**: usa un diseño predefinido o ajusta cada detalle
3. **Descarga el archivo**: elige un formato y una resolución
