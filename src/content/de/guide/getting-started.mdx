## Was QR Code Create leistet

QR Code Create macht aus einer URL einen QR-Code. Sie können die Farben ändern, ein Logo einfügen und dem Code einen Rahmen und eine Beschriftung geben. Außerdem können Sie UTM-Parameter hinzufügen, damit Sie in Google Analytics sehen, woher Ihre Besucher kamen.

Einen QR-Code zu erstellen dauert drei Schritte.

1. URL eingeben
2. Design anpassen (optional)
3. Datei herunterladen

**[QR-Code-Generator öffnen](/de/create)** (kostenlos, ohne Anmeldung). Sie können diese Anleitung beim Arbeiten geöffnet lassen.

## Schritt 1: URL eingeben

Öffnen Sie den [QR-Code-Generator](/de/create) und geben Sie im Feld unter „URL eingeben“ die URL ein, auf die der Code verweisen soll.

Der QR-Code erscheint in der Vorschau, sobald Sie tippen, und aktualisiert sich bei jeder Änderung.

Das Tool prüft die URL beim Tippen. Beginnt sie nicht mit `https://` oder `http://`, erscheint eine Fehlermeldung. Korrigieren Sie die URL, bevor Sie weitermachen.

## Schritt 2: Design anpassen (optional)

Im Bereich „Design anpassen“ ändern Sie das Aussehen des QR-Codes. Sie können diesen Schritt überspringen. Ein schlichter QR-Code lässt sich genauso gut scannen.

### Vorlage wählen

Es gibt fünf Vorlagen.

- **Schlicht**: klares Schwarz-Weiß
- **Business**: ruhig und seriös
- **Locker**: freundliche, natürliche Farben
- **Elegant**: fein und zurückhaltend
- **Pop**: hell und bunt

Sobald Sie eine Vorlage wählen, ändert sich die Vorschau sofort.

### Details anpassen

Nach der Wahl einer Vorlage können Sie weiter feinjustieren.

- **Logo**: Platzieren Sie Ihr eigenes Logo in der Mitte des QR-Codes
- **Farbe**: Ändern Sie Vorder- und Hintergrundfarbe
- **Rahmen**: Wählen Sie einen Rahmen um den QR-Code
- **Beschriftung**: Bearbeiten Sie den Text unter dem QR-Code

Halten Sie den Vordergrund deutlich dunkler als den Hintergrund. Das Tool zeigt das Kontrastverhältnis an und warnt Sie, wenn sich der Code möglicherweise schlecht scannen lässt.

## Schritt 3: Datei herunterladen

Wenn das Design passt, speichern Sie die Datei mit den Schaltflächen zum Herunterladen.

### Dateiformat wählen

- **PNG**: ein gängiges Bildformat für Bildschirm und Web
- **SVG**: ein Vektorformat, das in jeder Größe scharf bleibt und sich für große Drucke eignet
- **PDF**: ein Format, um den Code in ein Druck-Layout einzufügen oder an eine Druckerei zu schicken

### Auflösung wählen

Bei PNG können Sie auch eine Auflösung wählen.

- **Standard**: die Standardgröße, für Websites und andere Bildschirme
- **2x**: für den Druck (empfohlen), etwa bei Flyern und Visitenkarten
- **4x**: hohe Qualität, für Poster und Schilder. Die Datei ist größer

## UTM-Parameter hinzufügen

Wenn Sie denselben QR-Code auf mehreren Flyern oder Visitenkarten verteilen und wissen möchten, welcher einen Besuch gebracht hat, fügen Sie der URL UTM-Parameter hinzu.

Öffnen Sie unter dem URL-Feld den Bereich „UTM-Parameter hinzufügen“. Er enthält Felder für Quelle, Medium und Kampagne sowie Vorlagen für häufige Fälle wie Visitenkarten und Flyer. Wenn Sie eine Vorlage wählen, werden die Parameter für Sie ausgefüllt.

Google Analytics listet dann jeden Besuch unter der Quelle, dem Medium und der Kampagne auf, die Sie festgelegt haben.

## Zusammenfassung

Einen QR-Code mit QR Code Create zu erstellen dauert drei Schritte.

1. **URL eingeben**: Die Vorschau aktualisiert sich beim Tippen
2. **Design anpassen (optional)**: Nutzen Sie eine Vorlage oder passen Sie jedes Detail an
3. **Datei herunterladen**: Wählen Sie ein Format und eine Auflösung
